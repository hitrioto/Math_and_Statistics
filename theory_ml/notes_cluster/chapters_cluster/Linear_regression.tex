	\subsection{Naive Bayes}
	
	Теорема на Bayes с доказателство(припомняне): 
	\begin{theorem}[Bayes]
		$P(A|B) = \frac{P(B|A)P(B)}{P(A)}.$
	\end{theorem}
	\begin{proof}
		По дефиниция $P(A|B) = P(A\cap B)P(B)$ и $P(B|A) = P(B\cap A)P(A)$. Получаваме
		$P(A\cap B)= \frac{P(A|B) }{P(B)} = \frac{P(B|A) }{P(A)}$, откъдето следва равенството.
	\end{proof}
	
			
		

		In a Naive Bayes classifier, the root node represents the target class variable $Y$, and the leaf nodes represent the feature variables $X_1, X_2, \dots, X_n$. The network structure reflects the standard assumption that all features are conditionally independent given the class label.
		
		\begin{center}
			\begin{tikzpicture}[
			node distance=1.8cm and 1.2cm,
			state node/.style={circle, draw=blue!60, fill=blue!5, very thick, minimum size=1.2cm, font=\large}
			]
			% Central Class Node
			\node[state node] (Y) {$Y$};
			
			% Feature Nodes (positioned below the Class node)
			\node[state node] (X2) [below=of Y] {$X_2$};
			\node[state node] (X1) [left=of X2] {$X_1$};
			\node[state node] (X3) [right=of X2] {$X_3$};
			\node[draw=none] (dots) [right=of X3, xshift=-0.5cm] {$\dots$};
			\node[state node] (Xn) [right=of dots, xshift=-0.5cm] {$X_n$};
			
			% Directed Edges from Y to each X_i
			\draw[-{Stealth[scale=1.2]}, thick, red!70!black] (Y) -- (X1);
			\draw[-{Stealth[scale=1.2]}, thick, red!70!black] (Y) -- (X2);
			\draw[-{Stealth[scale=1.2]}, thick, red!70!black] (Y) -- (X3);
			\draw[-{Stealth[scale=1.2]}, thick, red!70!black] (Y) -- (Xn);
			\end{tikzpicture}
		\end{center}
		
		By applying Bayes' Theorem and the conditional independence assumption implied by the graph above, the posterior probability of the class $Y$ given the features is:
		
		\begin{equation}
		P(Y \mid X_1, X_2, \dots, X_n) = \frac{P(Y) \prod_{i=1}^{n} P(X_i \mid Y)}{P(X_1, X_2, \dots, X_n)}
		\end{equation}
		
		Because the denominator $P(X_1, X_2, \dots, X_n)$ remains constant for all classes, it acts as a scaling factor. The ultimate classification rule to predict the optimal class label $\hat{y}$ simplifies to:
		
		\begin{equation}
		\hat{y} = \arg\max_{y} P(Y = y) \prod_{i=1}^{n} P(X_i = x_i \mid Y = y)
		\end{equation}
